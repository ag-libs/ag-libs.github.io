## Lathe

A Java language server that works straight from your Maven build — no project
import, no classpath setup. It takes its whole model from the build, so the
editor never drifts from what actually compiles.

- [GitHub](https://github.com/ag-libs/lathe)
- [Maven Central](https://central.sonatype.com/artifact/io.github.ag-libs/lathe-maven-extension)
